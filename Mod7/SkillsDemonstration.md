1. NP stands for Nondeterministic Polynomial-time, where a given problem is solved in polynomial time. Three examples (that honestly I took from the book) are multiplication, sorting, and linear equation satisfiability. Nondeterministic means that even with the same input, there can be different ways to achieve the output. For multiplication, there are different ways it can be broken up or different properties of multiplication that can be applied to one problem. For sorting, there are a million sorting algorithms, each with their own time complexity, but different algorithms can be applied to the same input and find the output differently. Similar to the first two, linear equation satisfiability can be solved through different means and get the same output, especially with tools like Gaussian elimination.

Universality is the ability to break down the most complex algorithms into basic turing machines, thus, devices can be made to do a variety of things as each program within a machine can be simplified down to a what’s called a universal turing machine. Computability is the ability for a problem to be solvable with an algorithm. From computability, we get unsolvable problems–problems with no algorithm. Intractability deals with time complexity, specifically polynomial time versus exponential time.
